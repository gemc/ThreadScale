# ThreadScale Release 1.0.1

This version includes:

- rotated replicated sweeps that distribute thread-count ordering effects across runners;
- standard-deviation reporting and per-replica result tables and plots;
- more prominent CPU topology and runner metadata.

<br/>

# Release notes

- Replicated sweeps rotate their starting thread count by replica, reducing systematic bias from always running
  high-thread measurements last.
- Aggregate reports now show runtime standard deviation, while expandable tables and separate SVG plots retain
  the curve measured by each complete replica.
- Runner summaries now include OS-reported physical cores, sockets, hardware threads, and cgroup CPU limits when
  those values are available.

<br/>

## Documentation

- Documented replica rotation, the expanded report layout, runtime variability, and CPU topology metadata.
- Clarified that explicit thread lists and ranges preserve their written order.

<br/>

## Tests

- Added coverage for rotated matrices, explicit thread ordering, Linux topology parsing, per-replica
  aggregation, and replica plot artifacts.

<br/>

## Detailed list of changes and fixes

- Deduplicated explicit thread specifications without sorting them, enabling replica-specific execution order.
- Forced the `lscpu` parser to use the stable `C` locale and retained parsed topology fields in partial results.
- Added replica identifiers and runner descriptions to Markdown summaries and report JSON.
